# Wer startet wann? HYROX Hamburg 2026

Startzeiten der Gym-Crew beim HYROX Hamburg (28.10.–01.11.2026), damit wir uns an der Strecke anfeuern können.

- `index.html` – die Seite (GitHub Pages, Branch `main`, Ordner `/`)
- `starts.csv` – die Startliste: `Spitzname,Tag,Startzeit,Division,Zielzeit` (Zielzeit in Minuten oder h:mm, optional)
- `robots.txt` – hält Suchmaschinen fern

Neue Einträge: `starts.csv` bearbeiten und committen, nach etwa einer Minute zeigt die Seite die neue Liste.

Nach dem Event wird das Repository gelöscht.
